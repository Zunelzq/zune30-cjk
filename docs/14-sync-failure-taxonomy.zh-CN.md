# 同步失败问题总览（分类手册）

> "Zune 同步不了" 从来不是一个问题。这台设备的历史上至少存在七种互相独立的故障，
> 它们的症状高度重叠，甚至报到同一个错误码。本文把它们拆开，让你在动手改任何东西
> 之前先判断自己属于哪一类。

**范围：** Zune 30 / 80 / HD + Zune 4.8 桌面软件，Windows 7 至 11。
设备端的固件改动见 `07-sync-fix.md`；本文是那张"地图"。

---

## 0. 一句话版本

Zune 把要写进设备的每一样东西都包进一个**与设备绑定的 DRM 容器**。
这一个设计决定衍生出了大部分故障：它要求 PC 上有 WMDRM、设备上有匹配的许可证状态、
两边有有效的配对关系、以及一条能正常工作的存储路径。
其中任何一环缺失或损坏，同步就会失败——而且通常都报 `C00D11CD` 这一族错误。

---

## 1. 谁失败了，看起来是什么样

| # | 故障类别 | 典型症状 | 根因位置 |
|---|---|---|---|
| A | PC 缺少 WMDRM | MP3 能同步，WMA + 视频失败，`80004002` | Windows |
| B | WMVCORE 不兼容 | **只有视频**失败，同样是 `C00D11CD` | Windows / Zune 安装目录 |
| C | 设备库 / DRM 库损坏 | `80004005`、同步卡住、库为空 | 设备（`G:`） |
| D | 配对关系丢失 | "属于其他账户"、访客模式 | 设备 + PC |
| E | 许可证消失（服务关闭） | 购买/租赁的内容怎么都同步不了 | 微软服务器 |
| F | 存储硬件 | 同步卡死、设备冻结或掉线 | SSD/HDD、排线 |
| G | Windows 底层 | 根本认不到设备 | 驱动 / 服务 / 安装包 |

下面逐条展开。

---

## 2. 类别 A —— PC 缺少 WMDRM

**症状。** MP3 同步正常；所有 WMA（含有损和"无损"）失败；视频失败；
错误码 `C00D11CD (80004002)`；Zune 界面显示"正在转换…"然后放弃。

**原因。** Zune 在把 WMA 和视频写入设备之前，会用 WMDRM 加密它们。
这**不是版权检查**——连你自己压的、完全无 DRM 的 WMA 也会被包起来。
Windows 10 1607 之后逐步移除了 WMDRM；Windows 11 26H2 只留了一个 28 KB 的空壳
`wmdrmsdk-stub`。Zune 请求一个已经不存在的接口，而 `0x80004002` 就是
`E_NOINTERFACE`——"没有这个接口"。

**诊断。** Zune 运行时执行：

```powershell
Get-Process Zune | ForEach-Object { $_.Modules } |
  Where-Object { $_.ModuleName -match 'WMDRM' } |
  Select-Object ModuleName, FileVersion
```

没有输出 = 组件缺失或是空壳。

**修复。** 从 Windows 7 / 8.1 x64 里取回 `wmdrmdev.dll`、`wmdrmnet.dll`、
`wmdrmsdk.dll`、`drmv2clt.dll`、`drmmgrtn.dll`，逐个 `regsvr32` 注册。
完整步骤和回滚见 `07-sync-fix.md`。

**为什么 MP3 还能用：** MP3 是直接复制、不套 DRM 容器的。
这个"格式差异"是识别本类别最快的方法。

---

## 3. 类别 B —— WMVCORE，只有视频失败

**症状。** WMA 能正常同步，但视频失败，报同一个 `C00D11CD`。
有时转换步骤完成了，写入仍然失败。

**原因。** 是另一个组件：`ZuneEncEng.dll` 会加载 `WMVCORE.dll`，
而新版 Windows 自带的版本与 Zune 期望的编码管线不兼容。

**修复。** 社区工具 **Zune Modding Helper** 内置了一个可用的 `WMVCORE.DLL`，
并修改 `ZuneEncEng.dll` 的导入，让它从 Zune 安装目录加载这一份，而不是系统那份。
**不碰任何系统文件。**

**怎么区分 A 和 B：** 试一首 WMA。WMA 正常、只有视频失败 → B；
WMA 也失败 → A（或者两者都有）。

---

## 4. 类别 C —— 设备库或 DRM 库损坏

**症状。** `C00D11CD (80004005)`（注意是 05，不是 02）、同步卡在某个百分比、
设备上的库空了或重复了、同步中途设备重启。

**原因。** 设备在数据分区（`G:`）保存三个文件：

| 文件 | 作用 |
|---|---|
| `zunedb.dat` | 媒体库数据库 |
| `zunedb.BAK` | 它的备份 |
| `drmStore.dat` | 许可证 / DRM 状态 |

写入中断、刷机失败、或者开机失败后设备自动格式化 150 MB 分区，都会毁掉它们。
**重新刷固件并不会恢复这三个文件。**

**修复。** 把你自己的备份拷回去：

```powershell
Copy-Item zunedb.dat, zunedb.BAK, drmStore.dat G:\ -Force
```

然后**先重启设备**，再打开 Zune。

**预防：** 任何固件操作之前，先把这三个文件拷到电脑。
这是整台设备上最有价值的一份备份。

---

## 5. 类别 D —— 配对 / 所有权

**症状。** Zune 提示设备属于其他账户，或设备以"访客"身份出现；
同步被拒绝，或者曲库被清空并整库重传。

**原因。** 同步关系存在于**两边**——PC 上的 Zune 数据库，以及设备的库/DRM 状态。
重装 Windows、恢复设备、或换第二台电脑，都可能让两边对不上。
在设备上折腾固件实验也会造成同样结果。

**修复。** 用 Zune 的"更改同步关系 / 忘记设备"重新配对。
要做好曲库重建的心理准备：我们那次重新传输了 17 GB。

**注意。** 这是**状态问题**，不是硬件问题——设备是好的。

---

## 6. 类别 E —— 许可证已经不存在了

**症状。** 以前能同步（甚至保存在设备上）的内容，现在怎么都传不进去。
购买过的、订阅过的曲目，无论什么格式、什么电脑都失败。

**原因。** Zune Marketplace 于 2012 年停运，相关服务在 2015 年彻底关闭。
许可证由已经不存在的微软服务器签发。一次设备恢复或软件重装，
就可能让原本有效的内容变成不可用。

**修复。** 对"过期/无法获取"的许可证，**没有技术手段**。现实中可行的做法：

- 保持现有"设备 + PC"组合不要动，让既有许可证继续有效；
- 把长期曲库建立在无 DRM 的文件上（MP3、自己压的 WMA）；
- 接受"买过的内容在重置设备后可能播不了"这个事实。

这一类正是"动手前先备份"不是偏执狂的原因。

---

## 7. 类别 F —— 存储硬件

**症状。** 同步开始后卡住；设备冻结或从 USB 上消失；
即使在非同步场景下，"边听歌边浏览曲库"也会卡死。

**原因。** 要么盘快坏了，要么 ZIF 排线接触不良，要么——换了 SSD 之后——
PATA 驱动的 DMA 处理跟不上微秒级响应的新盘。

**修复。**

1. 重新插拔或更换排线（最常见的物理原因）。
2. 把盘接到 ZIF→USB 适配器上验证：PC 能读、能分区，盘大概率没坏。
3. 如果只是换 SSD 后在负载下冻结，看 DMA 修复：
   把 `drivers\builtin\pmc_atapi_mx31\device0` 的 `dma` 设为 `0`。
   详见 `13-field-notes.md` 和 `docs/announcements/reddit/` 下的 SSD 文章。

## 8. 类别 G —— Windows 底层

**症状。** 设备完全不被识别；Zune 一直卡在"正在连接"；安装包装不上；
设备管理器里显示在"其他设备"下。

**检查项。**

| 检查 | 方法 |
|---|---|
| Zune 通信服务 | `Get-Service WMZuneComm, ZuneWlanCfgSvc` |
| MTP/WPD 驱动状态 | 设备管理器 → 便携设备 |
| USB 口 / 线 | 换口、优先机箱后置、不要用 HUB |
| Zune 4.8 安装包 | 兼容模式，或用社区重打包版 |
| 设备卡在异常状态 | 同时按住 Back+Down 直到关机，再开机 |

**注意。** 设备只有在 **MTPZ 认证之后**才会通过 MTP 暴露存储。
没有可用的 Zune 栈时，设备可能只显示"充电中"、完全没有存储——
这是正常现象，不是故障。见 `12-mtpz-protocol.md`。

## 9. 决策树

```
开机后 PC 能看到设备吗？
├─ 不能 → 类别 G（驱动 / 服务 / 线材 / 设备状态）
└─ 能
   ├─ MP3 能同步吗？
   │  ├─ 不能 → 类别 C（设备库）/ D（配对）/ F（存储）
   │  └─ 能
   │     ├─ WMA 能同步吗？
   │     │  ├─ 不能 → 类别 A（WMDRM）
   │     │  └─ 能
   │     │     └─ 视频能同步吗？
   │     │        ├─ 不能 → 类别 B（WMVCORE）
   │     │        └─ 能 → 只有特定内容失败：类别 E
   └─ 是不是只有"买过/租过"的内容失败？
      └─ 是 → 类别 E（许可证问题，无技术解）
```

---

## 10. 错误码速查

| 错误码 | 最可能的类别 |
|---|---|
| `C00D11CD (80004002)` | A（WMDRM） |
| `C00D11CD (80004005)` | C（设备库 / DRM 库） |
| `C00D11CD`，只有视频 | B（WMVCORE） |
| "属于其他账户" | D（配对） |
| 设备根本不出现 | G（底层） |
| 同步中途卡死 | F（存储） |
| 只有特定内容失败、与格式无关 | E（许可证） |

---

## 11. 动手之前

1. 把 `G:\zunedb.dat`、`G:\zunedb.BAK`、`G:\drmStore.dat` 拷到电脑。
2. 把当前的 `F:\nk.bin`、`F:\EBoot.bin` 备份一份。
3. 记下设备固件版本和 Zune 软件版本。
4. 先试一首 **WMA** 和一个**视频**——哪个成功、哪个失败，
   是你手上最快的诊断信息。

本仓库其余内容，讲的是"光修好 PC 还不够"的那些情况。
